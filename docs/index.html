AssetPass

AssetPass는 Sunjin Jo가 운영하는 1인 프로젝트로, AI가 온체인 자산 상태를 점검하고 사람이 승인한 거래만 GIWA에서 실행·증명하는 Asset Passport를 만들고 있습니다.

우리가 풀려는 문제

온체인 자산을 운영하는 팀은 지급·정산·수수료 보충을 반복하지만, AI에 개인키를 맡길 수는 없습니다. Asset Passport는 AI가 잔액과 예정 거래를 점검해 실행안을 만들고, 정책 검사와 사람 지갑 승인을 통과한 거래만 GIWA에서 실행하게 합니다.

만든 것과 남은 일

프로젝트는 아직 초기 MVP입니다. 정책 기반 Test ETH 실행 컨트랙트와 테스트, AI 에이전트 역할, 거래 제안, 사람 지갑 연결 화면을 구현했습니다. 다음 단계는 GIWA Sepolia에 배포한 뒤 잔액 점검 → 거래안 → 지갑 실행 → tx hash 영수증을 실제로 연결하는 일입니다.
