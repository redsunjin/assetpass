AssetPass

AssetPass는 GIWA 위에서 토큰화 자산의 최신 문서 해시·검토 승인·공시 상태를 기록하고 검증하는 Asset Passport를 만들고 있습니다.

프로젝트 방식
기획·제품 의사결정·검증은 창업자가 책임지고, 조사·구현·문서화 과정에는 AI 도구를 협업 보조 수단으로 활용합니다.
현재 작업
증빙 레지스트리, 지갑 서명 흐름, 공개 검증 화면을 포함한 Asset Passport의 GIWA Sepolia MVP를 구축 중입니다.
핵심 강점
  • 복잡한 운영 요구를 집중된 제품 흐름으로 구조화
  • EVM 스마트컨트랙트와 프론트엔드 프로토타입 연동
  • 개인정보를 최소화하는 증빙·감사 이력 설계

프로젝트

Asset Passport는 자산을 보관·매매·투자 권유하지 않습니다. 발행자, 검토자, 감사자, 보유자가 현재 운영 상태를 확인할 수 있도록 문서 해시, 승인, 상태 이력, 공시 일정만 기록합니다.
