AssetPass

AssetPass는 Sunjin Jo가 운영하는 1인 프로젝트입니다. Asset Passport는 AI가 공시 위험을 먼저 찾고, 사람이 승인한 최신 공개 상태만 GIWA에 증명하는 RWA Release Gate입니다.

우리가 풀려는 문제

토큰화 자산은 토큰만으로 신뢰를 얻지 못합니다. 공시 직전 문서가 바뀌고, 승인 이력이 이전 버전에 묶여 있는 순간이 가장 위험합니다. Asset Passport는 AI가 그 불일치와 다음 행동을 먼저 제안하고, 책임자가 원문 근거를 보고 지갑으로 승인하게 합니다. 원본 문서는 체인에 올리지 않고, 문서 해시와 사람의 승인·상태 이력만 기록합니다.

만든 것과 남은 일

프로젝트는 아직 초기 MVP입니다. AssetRegistry 스마트컨트랙트와 테스트, AI의 위험 제안, 파일 SHA-256 직접 대조, 사람의 EVM 지갑 서명 미리보기까지 구현했습니다. 이제 GIWA Sepolia에 배포한 뒤 공시 차단 → 검토 승인 → 공시 전환 → 외부 검증의 실제 트랜잭션을 확인하려 합니다.
