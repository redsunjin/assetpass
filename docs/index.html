AssetPass

AssetPass is building Asset Passport, an evidence-only operating layer that records the latest document hash, review attestation, and disclosure status of tokenized assets on GIWA.

Project

Asset Passport does not custody, trade, or promote assets. It stores hashes, approvals, state history, and disclosure schedules so issuers, reviewers, auditors, and holders can verify the current operational record.
