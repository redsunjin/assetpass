# 제품 명세 v0.1

## 사용자와 역할

| 역할 | 하는 일 | MVP 권한 |
|---|---|---|
| 발행자 | 자산과 문서 버전을 등록 | 등록·갱신 요청 |
| 검토자 | 문서와 상태 변경을 검토 | 승인·반려 서명 |
| 감사자 | 이력과 증빙을 확인 | 읽기 전용·검토 서명 |
| 검증자 | 최신 상태를 확인 | 공개 읽기 전용 |

## 핵심 사용자 흐름

```text
자산 등록 → 문서 업로드/해시 생성 → 검토자 지갑 승인
→ GIWA Asset Registry에 상태 기록 → 공개 검증 화면에서 최신 상태 확인
```

## 데이터 모델

- `Asset`: ID, 이름, 자산 유형, 설명, 발행 주체(데모), 상태, 공시 예정일
- `DocumentVersion`: 자산 ID, 문서 종류, 버전, SHA-256, 업로드 시각, 상태
- `Attestation`: 대상 ID, 역할, 지갑 주소, 결정, 서명/트랜잭션 ID, 시각
- `DisclosureEvent`: 자산 ID, 제목, 기한, 상태, 연결 문서 버전
- `AuditEvent`: 행위, 주체, 대상, 이전/이후 상태, 시각

## GIWA 온체인 범위

Asset Registry는 최소 데이터만 저장한다.

- `assetId`와 현재 상태
- 최신 문서 해시 및 버전
- 상태 변경과 승인자의 주소·시각

원본 문서, 개인식별정보, 금액, 투자자 목록은 체인에 기록하지 않는다.

## 성공 기준

- GIWA 테스트넷에서 3개 가상 자산을 등록할 수 있다.
- 문서 버전 변경과 검토자 승인 이력이 트랜잭션으로 확인된다.
- 별도 계정 없이 검증 화면에서 자산 상태와 최신 증빙을 확인할 수 있다.
- 모든 화면에 `데모용 가상 자산 / 금융상품 아님` 고지가 보인다.
