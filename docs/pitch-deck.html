다음 검증

현재 구현된 범위

자산 계정, 거래안, 정책 검사, 지갑 연결, AI 공급자 설정을 한 화면에서 확인합니다.

다음 테스트넷 검증

잔액 점검 1회 → 거래안 1회 → 지갑 실행 1회 → GIWA tx hash 영수증 1회를 대조합니다.

AI는 개인키·자동 승인·자동 이체 권한을 갖지 않습니다. 테스트넷 배포 뒤에는 화면의 제안·정책, 컨트랙트·Explorer 이벤트가 같은 거래를 가리키는지 확인합니다.

07 / 08
Vision

AI 시대의 온체인 자산 운영,
실행 권한은 사람에게

AssetPass는 자산을 보관하거나 AI에게 송금 권한을 주지 않습니다. AI가 운영 리스크와 거래안을 먼저 보여 주고, 사람 지갑이 승인한 온체인 거래만 기록합니다.
