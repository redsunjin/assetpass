- 중복 트랙: `GIWA-native Ideas`
- 프로젝트명: **Asset Passport**
- 한 문장: **AI가 만든 온체인 거래안을 사람이 지갑으로 승인하고, GIWA에서 실행 결과를 대조하는 자산 통제 도구**

## 공식 프로그램 정합성

GASOK은 GIWA 체인 적합성, 독창성, 실행 가능성, 시장성, 팀 역량, GIWA Wallet 내 탑재 가능성을 본다. 테스트넷 MVP와 이후 메인넷 배포·사용자 지표가 프로그램 단계의 핵심이다. 공고 기준 추가 신청 마감은 2026-07-31이다.

공식 공고: <https://giwa.io/gasok>

| 평가 관점 | Asset Passport의 답 |
|---|---|
| GIWA 체인 적합성 | 제안 해시·정책 해시·지갑 실행·Test ETH 이동을 같은 EVM 체인에서 대조한다. |
| 독창성 | AI가 거래안을 만들되 개인키를 갖지 못하게 하고, 사람 지갑과 정책 컨트랙트가 실행 권한을 분리한다. |
| 실행 가능성 | Controller 배포, 허용 수신자·건당 한도 등록, Test ETH 0.001 실행, 중복 거래안 차단까지 GIWA Sepolia에서 확인했다. |
| 시장성 가설 | 초기 대상은 DAO·Web3 프로젝트·RWA 운영팀의 재무·운영 담당자다. 반복 지급과 수수료 보충에서 AI 자동화와 사람 통제가 모두 필요한지 인터뷰로 확인한다. |
| 월렛 적합성 | 표준 EVM 지갑으로 owner만 정책 등록·결제를 실행한다. GIWA Wallet이 공개되면 연동 후보로 검토한다. |

## 60초 피치 초안

DAO·Web3·RWA 운영팀은 지급·정산·수수료 보충을 반복합니다. AI가 잔액 부족과 예정 지급을 먼저 찾는 일은 유용하지만, 개인키와 무인 송금 권한을 AI에 줄 수는 없습니다. Asset Passport는 Asset Watcher가 거래안을 만들고, Policy Guard가 허용 수신자·건당 한도·중복 실행을 검사한 뒤, Controller owner 지갑만 결제를 실행하게 합니다. GIWA에는 제안 해시·정책 해시·승인 지갑·실제 자산 이동을 남깁니다. 테스트넷에서 Controller 배포, 정책 등록, Test ETH 0.002 예치, 0.001 실행, 중복 거래안 차단을 확인했습니다. 이 제품은 투자 권유, 자산 수탁, 토큰 발행 서비스가 아닙니다.

## 데모에서 반드시 보일 장면

1. Asset Watcher가 Test ETH 잔액 부족을 감지하고 Transaction Planner가 0.001 Test ETH 보충안을 만든다.
2. Policy Guard가 수신자와 건당 한도를 검사하고, Controller owner 지갑만 실행 버튼을 연다.
3. GIWA Explorer에서 `PaymentExecuted` 이벤트와 제안·정책 해시를 대조한다.
