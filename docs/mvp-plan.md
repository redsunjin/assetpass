# MVP 실행 계획

## 일정

| 시점 | 산출물 | 완료 판단 |
|---|---|---|
| D1 | UX 흐름·데이터·컨트랙트 인터페이스 | 3개 데모 장면이 와이어프레임으로 연결됨 |
| D2-D3 | Asset Registry와 테스트 | 등록·문서 갱신·상태 변경 이벤트가 테스트됨 |
| D4-D5 | 운영 콘솔 | 샘플 자산 및 문서 버전을 입력할 수 있음 |
| D6 | EVM 지갑 연결·서명 | MetaMask 등 EVM 지갑으로 발행자와 검토자의 서명 흐름이 동작함 |
| D7 | 공개 검증 화면 | 체인 이력과 최신 문서 해시를 읽음 |
| D8 | 영상·지원서·점검 | 3분 데모와 제출 자료 완성 |

## MVP 화면

1. **Asset List** — 가상 자산 3개와 현재 상태
2. **Asset Detail** — 라이프사이클, 문서 버전, 공시 캘린더, 감사 이력
3. **Review Queue** — 승인/반려와 지갑 서명
4. **Verify** — 자산 ID를 통해 최신 온체인 증빙 확인

## 구현 순서

1. GIWA 네트워크 설정과 지갑 연결 가능 여부 확인
2. 컨트랙트와 단위 테스트
3. 가상 데이터와 운영 UI
4. 컨트랙트 읽기/쓰기 연결
5. 데모 데이터 초기화 스크립트
6. 화면 녹화와 지원서 정리

## 보류 기능

- ERC-20/ERC-3643 등 실제 권리 토큰 발행
- 투자자 화이트리스트와 KYC
- 파일 원본 분산 저장소 연동
- 자동 배당·상환·정산
- 메인넷 배포
