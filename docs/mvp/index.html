자산 상태를 점검해 거래안을 만들고, 사람의 지갑 승인 뒤에만 실행하도록 설계한 테스트넷 데모

이 화면은 가상 자금과 고정 정책을 쓰는 테스트넷 데모입니다. AI와 규칙 엔진은 거래안을 만들 뿐, 개인키나 송금 권한은 갖지 않습니다. 최종 실행은 Controller owner 지갑만 합니다.

목표: 사람이 승인하지 않은 거래는 실행되지 않도록 한다.
